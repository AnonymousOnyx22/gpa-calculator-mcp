Where it is meant to go: Reddit (r/college, r/gradadmissions) and a student Discord

Just built GPA Calculator MCP because I got tired of doing grade math by hand.

It runs offline, needs no login, and you can ask it things like "what do I need on the final to get a B+" or "what's my weighted GPA if AP classes count 1.1x?". It also does CGPA/SGPA, converts grades, plans targets, and breaks down weighted parts.

If you want to try it: 
```bash
npx -y gpa-calculator-mcp
```

Add to Claude Desktop, Claude Code, Cursor, VS Code, or any app that supports MCP. Source: https://github.com/AnonymousOnyx22/gpa-calculator-mcp

Compared to pulling from Brightspace/Canvas, this is just for the numbers with no sign in. Happy to answer questions if you give it a shot.
